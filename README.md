A one-line Python program that writes the house cat's official excuse for the glass — one sentence, 142 characters, no apology and no confession. The cat's defence is that the glass was a non-paying tenant who had been staring at it all morning, so it served an eviction notice and gravity was only the courier. Running the program writes that line to `/output/entry.txt`, guarded to 1–200 characters.

## Run it

```sh
python3 main.py
```
